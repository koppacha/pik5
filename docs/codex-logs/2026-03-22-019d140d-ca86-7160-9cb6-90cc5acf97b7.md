現実的には、少なくとも「明度差」か「色相差」のどちらかをはっきり取る必要があります。今のように近い色相・近い明度だと、隣接配置ではほぼ同一グループに見えます。

実務上の目安はこのくらいです。  
- 軽い差別化: 同色相で明度差 15〜20% 程度
- はっきり差別化: 同色相で明度差 25〜35% 程度
- 強調ボタン向け: 色相差 20〜40度 + 明度差 20% 前後、または補色寄りに少し振る

今回の用途だと、`active` は「ページ文脈に属する操作」、記録投稿ボタンは「最重要CTA」なので、かなり差を出してよいです。  
おすすめは次のどちらかです。  
- `main` はやや落ち着いた中明度、`accent` は高彩度・高明度
- `main` はシリーズ色、`accent` はその補助色ではなく暖色寄り/発光感のある色にずらす

特に黄色系のシリーズ4は、単に明るくすると背景や白文字と競合しやすいので、`main` を少し鈍く、`accent` を橙寄りにする方が目立ちます。  
例:
- series4 main: 落ち着いた黄土寄り
- series4 accent: 鮮やかなオレンジ寄り

目安としては、記録投稿ボタンだけは  
- 周囲の `active` ブロックより彩度を 1段強くする
- さらに border か shadow も 1段強くする  
くらいが現実的です。

結論として、CTA を目立たせたいなら「少し違う」では足りず、`main` と `accent` は視覚的に別カテゴリと分かる程度、少なくとも中程度以上の色差を付けるのが妥当です。必要なら次に、今の6パターンそれぞれについて「差を強めた配色案」を具体的なカラーコードで出します。
