# 第20回案と研究の扱い

- 継続更新する正本は `next/pages/limited/tricks/docs/tricks-tournament-20-plan.md`。採用・不採用・未決、ユーザー指定と実装仮定、シミュレーター反映と本番反映を分ける。
- 現行シミュレーター既定はv20。本番APIへの一律適用を意味しない。v19再現を維持し、第19回確定結果・リプレイへ新ルールを適用しない。
- 採用案は固定83/12/4/0.9/0.1%排出、全投稿者最低1P＋順位重み2:1、更新1P、全初投稿無料・15分延長、有料延長15→10→5→5、本人テイクコスト未満の定期給付、切り札上限max(累計参加登録人数−1,8)。詳細境界は計画書を正とする。
- 追加テイク費、レア度ボーナス8P上限は不採用。セントラル・ショップ・新徴収は独立研究であり既定に導入していない。
- ユーザー方針：中央赤字を失敗条件としない。流動性は取引量とプレイヤー活動量で評価し、RP帯とDP富裕度、発行と実支給を混同しない。
- シミュレーターの予想報酬近似・v19配分と本番式の差を評価時に確認する。有限seedの無発生を保証とせず、未使用seed・会計不変条件・下位個人への影響も見る。
- 実験値・旧案は機能配下 `docs/studies/` と整理前資料に保持する。共通コンテキストへ研究の時系列を積み重ねない。
