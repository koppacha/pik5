# 記録・採点の契約

- 投稿経路は `RecordForm` → Next `/api/server/post` → Laravel `RecordController`。NextAuth、same-origin、サーバー入力検証、Laravel側の署名・業務条件を確認する。
- 内部 `post_id` と公開 `unique_id` は別。編集時はunique_idを維持する。管理訂正は対象ロック・再集計・監査を行い、通常投稿の課金・延長経路を代用しない。
- 再現は [専用ユーザーでの投稿確認](../testing-post-api.md)。通常seedは実ユーザー資料を読むため実行しない。実データへ書く検証は対象・後始末を明確にする。

- 記録詳細はSSRセッションを引き継ぐ。投稿成功後はISR再検証を待ち、`onPosted` または `router.replace` で表示を更新する。フルリロードで認証を再取得しない。投稿のHTTPエラーはフォームに表示し、入力値を保持する。

## 証拠と型

- 新規登録者は登録後満30日未満または投稿数30未満。ルール別証拠要件は `next/lib/const.js`。自然数は順位境界、0は不要、qは常時必要。動画があれば画像義務を免除する。
- rule91のstage901 / 902は動画不要・画像必須の例外。画面yupだけでなく投稿APIでも検証する。rule48や大会はmetadata / 専用条件を確認する。
- 公開ステージコードと内部キーを分ける。数字範囲や百の位だけでシリーズ・イベント・許可を判断しない。rule48はカタログ、トリックは大会コンテキストから解決する。

## スコアと順位

- ステージの年別フィルターは `RecordController::show()` で翌年1月1日未満・`flg < 2` の候補からユーザーごとの自己ベスト（同点は先着）を選び、順位・RPを再計算する。通常の新規投稿は旧記録を残すので翌年の記録更新後も前年を抽出できる。投稿日時が最後の行を選ぶ処理ではない。
- 再編集・削除で `flg=2` になった行は過去年の指定でも復元しない。この既存仕様と、通常投稿による自己ベスト更新の年別抽出を区別する。
- `score2str()` は `next/lib/factory.js`。通常のカウントダウンは残り秒→経過時間表示、タイムアタック系は経過秒。表示単位と順位方向を別に確認する。
- 総合タイムアタックrule29 / 35 / 47は各ステージ `max(0,600-score)`。`TotalController::scoreForTotal()` をユーザー集計でも共用する。
- rule48は採点metadataと公開済みユニーク対象を使用する。通常総合へ含め、特殊総合へ含めない。
- rule48の認定記録は`post_memo`の専用トークン`[pik5:dandori-certified:v1]`で区別する。新カラムは使わず、公開APIはメモ全文を隠して`is_certified`だけ返す。編集時は復元・解除・旧クライアントの未指定時の保持に対応し、共通Recordのタグ直前に認定アイコンを出す。[詳細](../dandori-certified-world-records.md)。
- 公式世界記録の報告はルール31/32/33/34/36/48だけで、`world_record_reports`へ保存する。通常記録や総合へ混ぜない。認証主体を署名から固定し、有効報告の機種別最良値（同点は最初）を参考ボーダーとして使う。画像は一般投稿と同じpublic/imgと配信経路。ピクミン3の時間入力は経過秒から既存の内部スコアへ変換し、48の秒数は変換しない。
- 世界記録の301〜330・345〜350はWii U/Switch、331〜344とrule48はSwitch固定。時間は時:分:秒入力から変換する。現行管理者10のみ確認後に論理削除でき、管理者削除3件以上で世界記録報告だけを非活性・API拒否する。削除再送は加算しない。投稿者単位の行ロックで投稿と削除を直列化する。
- トリックの時間は整数秒。`TrickScoreOrder` の明示score_orderを優先し、未指定timeでは元419〜428と投稿先1356はDESC、他はASC。pointsはDESC。本文から推測しない。
- 同点は標準競技順位1,1,3、ホルダーは最良記録の先着1人。RP・還元の同順位配分とホルダー確定を混同しない。
- 第19回の名称は `withEventCardNames` によりカードtitle / rule_nameを一覧・個別・履歴へ付ける。通常記録・他大会を上書きしない。ピックアップ動画も元ステージ＋カードルールを使う。
- 総合ID1〜3は互換APIのscore / rps反転を画面で正規化する。画面内の順位基準切替・参考スコアの連続挿入・0表示を維持する。
- ダンドリバトルの同点報酬は該当順位合計を等分。ボーダーでrank0を除外する。

## 年別記録ページ

- `/date/[year]` はステージと同じ年末自己ベストを横断取得し、2015年以降は代表記録の投稿日を当年内へ限定、2014年だけ以前も含む。順位・RPの母集団は下限で切らず、動画フィルターでも再計算しない。選別は `StageRecordRanking` を共用する。
- 通常／特殊／期間限定はRP降順、RTAは `speedrunStageConfigs` に限定した投稿履歴から種目・機種別タイム順。RTAに独自RPを導入しない。分類・キャッシュ・更新手順は [年別記録ページ](../yearly-record-page.md)。
