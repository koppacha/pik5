# Median実装・確認

## 実装内容

`/limited/median` は匿名・ログイン混在の中央値ゲーム。ユーザーが指定した「30桁は例」「主催の明示終了」「終了から24時間保持」を適用する。既存記録の投稿・総合点・投稿数と独立する。

初回の参加時に主催・参加者を選択する。匿名は名前の完全一致のみで再入場し、端末が違っても同名なら得点と役割を復元する。ログイン参加はPrismaの現行Userから取得したuserIdで区別する。同じ表示名も許す。主催のタブ閉鎖や通信断では終了しない。

進行は「待機→回答受付→回答回収→締切・採点・保存→開示→次問」。回答保存ボタンは設けない。入力中は400msの下書き自動保存を行い、主催の締切操作時は主催自身の最新入力を必ず送信する。他の参加端末は締切通知を受け取ると入力を停止し、その時点の最新入力を自動で最終送信する。全員の回収完了または8秒経過後に採点する。通信断・応答のない端末は最後に保存できた下書き（未入力は採点対象外）を使う。ネットワーク越しに各端末へ通知するため、主催のクリックと全端末の停止が厳密に同時になる保証はしない。回収中は遅延した通常の自動保存で値を上書きさせず、最終送信も対象者ごとに1回だけ受け付ける。

出題時の参加者と受付中の途中参加者をその問題の対象にする。途中離脱しても当該回答・獲得点は保持する。締切後に初参加した人は0点で次問から回答する。新ゲームは主催・参加者・出題キュー・未取込の投稿を引継ぎ、得点のみをリセットする。旧問題の履歴は旧ゲームに保存し、新画面は出題待ちになる。

「次以降のお題」はフォーカスアウト時に自動保存し、「お題を保存」ボタンは設けない。空行・空白しかない場合は「お題表示」を無効にする。保存中の追加入力や保存失敗時の内容は保持し、出題・お題受信・新ゲーム開始は未保存のキューの保存完了を待つ。フォーカスアウト直後の出題でも保存要求を重複させない。

終了後は全変更を停止する。主催による新ゲーム開始だけは可能。終了済みセッションは24時間保持し、期限で参照不可、毎分のpruneで物理削除する。公開APIは現在のゲームのみ返し、旧ゲームIDを指定して閲覧する機能は含めない。

## 数式

math.jsの任意精度計算をworkerで実行し、計算64桁、比較30有効桁、余剰桁は0方向へ切り捨てる。精度と対応範囲はイベント向け近似であり、数学的な恒等性は保証しない。例として `log(8,2)` が3よりわずかに小さい近似になり、切り捨て後に3と別の比較値になる場合がある。

有限実数のみを許し、原文・比較値（科学表記）・表示値・入力の有効性を別フィールドに保存する。巨大数の比較をPHP floatやJS Numberに変換しない。最小・最大は−1、重複除去した値の上側中央値は+2、中央値優先、その他0。未入力・空白のみは採点・開示回答の対象外、無効な非空の式は0。

対応関数・定数は画面の「有効な定数・関数」に列挙し、入力上限は評価器で制限する。大学数学で使う初等関数・組合せ・ガンマ関数等の有限実数の数値評価が対象で、記号積分・一般の方程式解法・行列・複素数を無制限に扱わない。
