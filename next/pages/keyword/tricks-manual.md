# トリックテイキング制 ユーザーマニュアル

カードに書かれた期間限定チャレンジでスコアを競い、ランクポイントを集める大会です。自分でカードを場に出すほか、ほかの参加者が出したカードの期間限定チャレンジにも参加できます。

このマニュアルはルールの細かい仕様について説明します。

## 1. まずは遊んでみましょう

1. 開催中の大会ページを開き、ログインして「参加する」を押します。最初に**5P**を受け取ります。
2. 場に出ているカードに書かれたルールに従ってピクミンをプレイし、スコアを出しましょう。クリックするとランキングが開き、その場で投稿できます。**ほかの人が出したカードへの初投稿は無料**です。
3. 自分で期間限定チャレンジを提案したいときは、「ドロー」で手札を集めます。1枚につき**1P**を使います。
4. 必要な枚数が集まったら、手札から1枚を選んでテイクします。選んだカードが場に出て、全員が挑戦できるようになります。
5. 切り札の期限が来ると自動的に回収され、順位に応じたランクポイントとドローポイントが還元されます。

最初のテイクには手札が**2枚以上**必要です。テイクすると**選ばなかったカードは使えなくなる**ので、出したいカードをよく吟味してから出しましょう。

## 2. 大会の目的と参加について

### 勝敗の決まり方

大会終了時に**合計ランクポイントが最も多いプレイヤー**が優勝（MVP）になります。また、もっとも多くのカードで１位になり回収したプレイヤーも**トップホルダー**として表彰されます。他にもいくつかの表彰対象があります。
ドローポイントを多く持っていたり手札を多く残していたりしても、それだけでは表彰対象になりません。期間限定チャレンジへ参加して順位を上げることが、ランクポイントの獲得につながります。

### 参加状態の保存

一度参加すると大会から退出することはできません。ページを閉じたりログアウトしたりしても、手札、ドローポイント、成績は保存されます。

自分より後に新しい参加者が増えるたびに、既存の参加者は1Pを受け取ります。同じ人が参加操作をやり直しても、初期ドローポイントやこのボーナスが増えることはありません。

## 3. 画面と用語の見方

| 表示・用語 | 意味                                                     |
|---|--------------------------------------------------------|
| ドローポイント（P・DP） | ドローや投稿などに使う残高です。省略してポイントと呼ぶこともあります。                    |
| ランクポイント（R） | 期間限定チャレンジの順位から得る成績です。大会の勝敗は合計Rで決まります。                  |
| デッキ | ドローできるカードです。全員共通です。クリックすると内訳を確認できます。                   |
| 手札 | 自分が持っているカードです。内容は自分だけが確認でき、内容の情報共有はルール違反となります。         |
| 切り札 | テイクされて場に出たカード（トリックの先頭カード）です。ここに書かれたルールで競い合います。         |
| テイク | 手札の1枚を場に出し、その期間限定チャレンジへの挑戦を呼びかける操作です。                  |
| テイカー | そのカードをテイクしたプレイヤーです。                                    |
| トリック | テイクで使った手札のまとまりです。選ばなかった手札は切り札が回収されるまでここに留まります。         |
| 捨て札 | 切り札の回収後、切り札以外のカードを置く場所です。デッキが枯渇したとき、補充に使われます。          |
| 回収 | 切り札のカウントダウンがゼロになったとき、１位のプレイヤーの元に移動し、ポイント還元などを確定する処理です。 |
| ホルダー | 回収時に1位となり、そのカードを獲得したプレイヤーです。                           |
| クリエイター | カードのルールを考案したユーザーを指します。                                 |
| ポット | 徴収されたドローポイントや手札返却費をため、後で還元する共通の蓄えです。                   |

プレイヤー一覧では、各参加者のドローポイント、手札枚数、レベル、テイクコスト、合計ランクポイントなどを確認できます。

## 4. 手札を集めてテイクします

### ドローと手札の上限

ドローは1枚につき1Pです。残高が1P以上あり、手札が上限に達していない場合に引けます。デッキの各カードは同じ確率で選ばれます。

テイクの累計回数に応じてプレイヤーレベルが上がり、テイクに必要な手札枚数と手札上限も増えます。「テイクコスト」は**必要な手札枚数**を示しています。

| その大会でのテイク成功回数 | レベル | テイクに必要な手札 | 手札上限 |
|---|---:|---:|---:|
| 0回 | 0 | 2枚 | 6枚 |
| 1〜3回 | 1 | 3枚 | 9枚 |
| 4〜8回 | 2 | 4枚 | 12枚 |
| 9〜15回 | 3 | 5枚 | 15枚 |

レベルは「テイク成功回数の平方根の整数部分」です。必要手札枚数は「レベル＋2」、手札上限はその3倍です。

### テイクできる条件

必要枚数以上の手札を持ち、切り札の枠が空いていればテイクできます。切り札の上限は「累計参加者数−1枚」を基本に、最低1枚、最大16枚です。

初回のテイクは待ち時間がありません。2回目以降は、前回のテイクから**60分**待ちます。切り札が早く回収されても待ち時間は変わりません。反対に、切り札が残っていても60分経てば次のテイクができます。

大会終了の**2時間30分前からは待ち時間が免除**されます。ただし、**終了1時間前以降はテイクできません**。

### トリックとレア度ボーナス

手札から1枚を選んでテイクすると、残りもすべてその切り札に重ねられます。例えば、手札3枚でテイクした場合、切り札1枚と残り2枚を合わせてトリック数は3です。

選んだカードのレア度によって、回収時に配るドローポイントの原資へボーナスが加わります。以下の表では、トリック数を3で割り、小数点以下を切り捨てた値を「g」としています。

| レア度 | ボーナス | 手札3枚でテイクした例 |
|---|---|---:|
| C1 | 0Pです。 | 0P |
| U2 | g＋1Pです。 | 2P |
| R3 | g＋4Pです。 | 5P |
| E4 | 2×g＋7Pです。 | 9P |
| L5 | 3×g＋15Pです。 | 18P |

テイク前の「トリック数」表示には、手札枚数とこのボーナスを足した値が表示されます。実際のカード枚数が増えるわけではありません。

### 練習と手札の返却

手札のルールを確認できるのはそれを持っているプレイヤーのみですが、他の人に隠れてこっそり手札のルールを練習することはルール違反にはなりません。ただし、練習で出た記録を温存しておき、テイクしてから出すことはできません。期間限定ランキングでは、あくまでも投稿可能になってからプレイして出した記録のみを提出できます。（クリエイターのテストプレイまで含めると厳密な遵守は難しいので、あくまでも「非公開ステージのやり込みは控えてね」というお願い程度のルールになります）

不要な手札は「デッキに戻す」で1枚につき1Pを使って返却できます。別のカードを引くにはさらに1Pが必要なので、返却とドローの合計は2Pです。返却したカードの難易度とレア度は変わらず、誰かが再び引くことがあります。

### デッキの補充とレア度

最初のデッキは160枚です。デッキがなくなると捨て札がデッキへ戻ります。デッキと捨て札の両方が空の場合はドローできません。

ドロー時にレア度が未確定のカードは、次の確率でレア度が決まります。

| レア度 | 終了3時間前より前 | 終了3時間前以降 |
|---|---:|---:|
| C1 | 87% | 0% |
| U2 | 8% | 87% |
| R3 | 4% | 8% |
| E4 | 0.9% | 4% |
| L5 | 0.1% | 1% |

捨て札からデッキへ戻ったカードは、次のドローでレア度が再抽選されます。手札から直接返却したカードは、確定済みのレア度を保ちます。

レア度を抽選した本人が引いた時点では「開封済み」は表示されません。レア度を保持したまま手札から返却され、再び引かれたカードには「開封済み」が表示されます。捨て札に回るとこの表示はリセットされ、次に引いた人がレア度を再抽選します。手札から返却された履歴のあるカードには、返却履歴のアイコンも表示されます。

## 5. 期間限定チャレンジを遊んで投稿します

切り札をクリックし、ルールと期限を確認してください。指定された期間限定チャレンジをルールどおりに遊んだら、切り札の詳細から「投稿」を押してスコアを入力します。スコアは**1〜999999の整数**で投稿できます。

### 投稿にかかるドローポイント

| 投稿の種類 | 費用 |
|---|---|
| 他の人がテイクした切り札への初投稿 | 無料です。 |
| 自分がテイクした切り札への初投稿 | 難易度と同じPを使います。 |
| 同じ切り札への2回目以降の投稿・更新 | 難易度と同じPを毎回使います。 |

例えば難易度3の切り札では、テイカーの初投稿と、誰でも2回目以降の投稿に3Pが必要です。

**投稿費は、残高が不足していても支払えます。**その結果、ドローポイントがマイナスになることがあります。ドロー、手札返却、延長は借金して支払えず、それぞれ必要な残高が必要です。

記録を削除してから投稿し直しても、初投稿には戻りません。再投稿は有料で、支払い済みのドローポイントも返金されません。

### 順位とランクポイント

各プレイヤーの有効な最良スコアで順位を決めます。スコアが大きいほどよいか、小さいほどよいかは、対象期間限定チャレンジの順位設定に従います。

ランクポイントは**「投稿者数−順位＋1」R**で、さらに**1位には1R**が加わります。投稿者数は、現在有効な記録を持つ人数です。

| 投稿者数 | 順位とランクポイントの例 |
|---|---|
| 1人 | 1位は2Rです。 |
| 3人・同点なし | 1位は4R、2位は2R、3位は1Rです。 |
| 3人・2人が同率1位 | 同率1位はそれぞれ4R、残りの1人は3位で1Rです。 |

切り札の成績は、投稿・更新・削除によって変わります。プレイヤー一覧の合計Rには、回収済みの確定分と、現在の切り札の暫定分が含まれます。

## 6. 切り札の期限と延長について

切り札の期限はテイクした時点から始まります。

| 難易度 | 最初の制限時間 |
|---|---:|
| 1・2 | 60分 |
| 3 | 80分 |
| 4 | 100分 |
| 5 | 120分 |

### 初投稿による自動延長

各プレイヤーの初投稿によって、切り札の期限が延びます。テイカーの初投稿も対象です。

| 切り札への参加順 | 延長時間 |
|---|---|
| 1人目で、投稿直前の残り時間が15分未満 | 30分延びます。 |
| 1人目で、残り時間が15分以上 | 15分延びます。 |
| 2人目以降 | 10分延びます。 |

残り15分ちょうどの場合は15分の延長です。同じプレイヤーの更新や、削除後の再投稿では延長されません。

### ドローポイントを使った延長

切り札の「延長」から**1Pで15分**延ばせます。大会参加者なら、自分が出したカードや投稿済みのカードでなくても延長できます。

延長には残高1P以上が必要です。切り札の期限に達した場合、大会終了1時間前以降の場合、すでに期限が大会終了時刻以降の場合は延長できません。

任意延長の上限は大会終了時刻です。そこまで15分未満しか延ばせない場合も費用は1Pです。条件を満たしていれば、改めて操作して何度でも延長できます。

初投稿の自動延長で期限が大会終了時刻を超えた場合でも、大会終了時には回収されます。

## 7. ドローポイントの給付と徴収について

### 毎時00分・30分の給付

毎時00分と30分に、**手札枚数＋ドローポイントが3未満**なら1Pを受け取れます。切り札の有無にかかわらず判定され、マイナスの残高もそのまま計算に含まれます。

例えば、手札1枚・残高1Pなら合計2なので対象です。手札2枚・残高1Pなら合計3なので対象外です。条件を満たし続ければ、次のタイミングでも受け取れます。

給付時刻より後に参加した場合は、次の給付時刻から対象になります。画面の給付対象表示は現在の状態で変わるため、給付前に残高や手札が増えると対象外になることがあります。

### テイク・無料初投稿時の即時給付

**操作直前の手札枚数＋ドローポイントが5未満**で、テイクまたは他の人の切り札への無料初投稿が成功すると、その場で1Pを受け取れます。

テイクでは、使う前の手札枚数で判定します。例えば、手札3枚・残高1Pなら合計4なので対象ですが、手札3枚・残高2Pなら合計5なので対象外です。

無料初投稿による支給は、各プレイヤー・各切り札につき1回だけです。更新、削除後の再投稿、有料投稿では支給されません。

### 全員が不足しているときの補充

切り札が0枚で、参加者全員の「手札枚数＋ドローポイント」がそれぞれ3未満になると、全員が合計3になるように不足分のドローポイントが配られます。1人でも合計3以上の参加者がいれば、この補充はありません。

### 再分配システムとポット

毎時00分・30分の給付後、残高が**テイクに必要な手札枚数×5Pを超えている**場合は1Pが徴収されます。

例えばLv.0では11P以上、Lv.1では16P以上が対象です。画面の「税金徴収ボーダー」で確認できます。手札枚数はこの残高判定には足しません。

徴収されたドローポイントと手札返却費はポットへ蓄えられ、次に投稿者がいる切り札を回収したときに全額が還元へ加わります。

## 8. 回収とドローポイント還元について

### 回収されるとどうなるか

切り札の期限が来ると、最終順位、ランクポイント、ドローポイント還元が確定します。**回収時に1位のプレイヤーは、そのカードのホルダーになります。**同率1位の場合は、1位となる記録を先に登録した1人が獲得します。

回収された切り札は、その大会中には再登場しません。重ねていた残りのカードは捨て札へ移ります。誰も有効な記録を持っていない場合、還元は発生せずにその切り札のポイントは消滅し、切り札は除外されます。消滅したポイントはポットへ入りません。既存のポットは次の投稿者がいる回収まで保持されます。

### 還元されるドローポイントの原資

投稿者がいる場合、次の合計を全額配分します。

**トリック数＋レア度ボーナス＋その切り札への投稿費・延長費＋今回加わるポット**

例えば、手札3枚でR3をテイクし、投稿費・延長費の合計が2P、今回加わるポットが1Pなら、原資は「3＋5＋2＋1」で11Pです。

投稿者が1人なら、その人が全額を受け取ります。2人以上の場合は順位に応じて分配します。全員に同じ額が配られるわけではありません。

### 順位ごとの分配

原資が「投稿者数＋3」Pの場合、同点がなければ次の分配になります。

| 投稿者数 | 総額 | 1位から順の還元 |
|---|---:|---|
| 2人 | 5P | 3P・2Pです。 |
| 3人 | 6P | 4P・2P・0Pです。 |
| 4人 | 7P | 4P・2P・1P・0Pです。 |
| 5人 | 8P | 3P・2P・2P・1P・0Pです。 |

原資が多い場合は、順位間の差を調整しながら1Pずつ加算します。少ない場合は、下位側の正の配分から減らします。3人以上では最下位の順位配分は常に0Pです。

同順位の人がいる場合は、その人たちが占める順位枠の合計を均等に分けます。割り切れない余りは、投稿の有無にかかわらずテイカーに全額還元されます。通常は1〜3P程度ですが、大人数の同点ではこれを超えることがあります。同順位の均等配分は保たれます。

### 「総還元P」とランキングの見込み表示

切り札の「総還元P」は、**トリック数＋レア度ボーナス＋投稿費・延長費**です。投稿者がいる切り札のうち期限が最も早い1枚には、現在のポットも加算します。延長などで期限の順序が入れ替わった場合は、加算先と表示額を再計算します。また、投稿者がいない場合も表示されますが、回収時に有効な投稿者がいなければ還元はありません。

ランキングの `[4r/3p]` のような表示は、左が暫定ランクポイント、右がその順位で回収された場合の還元見込みです。

還元見込みでは、投稿者がいる切り札のうち期限が最も早い1枚へ、現在のポットを加えています。他の投稿、延長、徴収、回収によって変わるため、確定額ではありません。テイカーが投稿している場合、端数はその人の見込み額へ含まれます。テイカーが未投稿なら、ランキング内の「テイカー端数還元」に別枠表示します。投稿者がいるカードでは、順位別見込み額とこの別枠分の合計がカードの「総還元P」と一致します。

### 管理者裁定によるルール変更・ランキングリセット

大会当日、個別裁定でルールが変更されることがあります。管理者は切り札のランキングから「ルール変更」でルール名・本文などを更新できます。大幅な変更では「リセット」を選び、「ランキングをリセットしますか？」の確認後、「リセットする」で有効投稿をすべて無効にすることがあります。

削除記録には管理者による削除日時が残ります。投稿・延長の支払い履歴、発生済みポイント、総還元ポイントは巻き戻りません。**リセット後の再投稿も2回目以降として有料**です。

リセット直前に有効な投稿があった参加者には、**お詫びとして即時5P**を配布します。既に全投稿を削除済みの人や未投稿者は対象外です。同じリセットの再送で二重配布されることはありません。

補償対象者は、次の毎時00分・30分の給付・徴収タイミングで**徴収を1回免除**されます。徴収対象の残高でなくても、その最初のタイミングで免除は使い切りとなり、次回以降は通常どおり徴収されます。複数リセットを受けても未使用の免除回数は積み重なりません。

## 9. 観戦と大会終了後の楽しみ方

### 観戦モード

ログインしていない人や、まだ参加していない人も観戦できます。「観戦する」、または画面の観戦モードボタンから切り替えます。

観戦中は切り札、ランキング、プレイヤー情報、公開ログを見られます。手札やデッキ、ゲーム操作コマンドは隠れ、投稿や延長はできません。遊びたい場合は通常表示へ戻るか、参加・ログインの案内から進んでください。

参加済みの人が観戦へ切り替えても、参加状態や成績、ドローポイント給付の資格は維持されます。

### 大会終了とコレクション

終了時刻になると、残っている切り札がすべて回収され、最終成績が決まります。終了後はドロー、テイク、投稿、延長ができません。残ったドローポイントや手札はランクポイントへ変換されません。

結果一覧では、ホルダーがいる回収カードの最終ランキング、総還元ドローポイント、場に出ていた時間を確認できます。獲得したカードはコレクタールームでも閲覧できます。

## 10. 困ったときに確認すること

| 延長できません。 | 残高、切り札の期限、終了1時間前の締切、大会終了時刻まで延長済みかを確認してください。 |
| 操作ボタンが見当たりません。 | 観戦モードになっていないか、ログイン・大会参加が済んでいるか、大会が開催中かを確認してください。 |
