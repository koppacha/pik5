# next/pages

このディレクトリは Next.js のルーティング入口です。画面ページと API ルートの両方が含まれるため、UI とサーバー処理の境界を把握するうえで重要です。

## 重要ファイル

### `_app.js`
- 全ページ共通のアプリケーション入口です。
- `Layout`、`SessionProvider`、`ThemeProvider`、Emotion Cache、Google Analytics、共通 SEO、ページ遷移ローディングをまとめて設定しています。
- 全体挙動に影響する変更はまずここを確認してください。

### `index.js`
- トップページです。
- SSR でユーザー一覧とトレンド情報を取得し、`DashBoard`、新着記録、投稿数ランキング、トレンド表示を構成します。
- サイトのホーム導線や初期表示の変更時の中心です。

### `stage/[...stage].js`
- ステージ別ランキングページです。
- `getStaticProps` で Laravel API からステージ情報、投稿一覧、ルール本文、攻略情報を取得し、投稿一覧・絞り込み・投稿導線をまとめて表示します。
- ランキング閲覧体験の中核ページです。

### `total/[...series].js`
- 総合ランキングページです。
- シリーズ別または総合カテゴリ別の集計結果を取得し、総合ランキング UI を描画します。
- 集計表示の変更では Laravel 側の `TotalController` とセットで確認が必要です。

### `record/[record].js`
- 記録個別ページです。
- 単一記録の詳細表示、履歴表示、再編集・削除導線を持ちます。
- 編集権限や削除導線の UI 変更時の主要ファイルです。

### `auth/login.js`
- NextAuth の資格情報ログイン画面です。
- フォームバリデーション、エラー表示、ログイン後遷移を担当します。
- 認証 UI を触る際の入口です。

### `api/auth/[...nextauth].js`
- NextAuth 設定本体です。
- Credentials 認証、Prisma Adapter、JWT/Session コールバック、メール情報のセッション反映をまとめています。
- 認証仕様変更時の最重要ファイルです。

### `api/server/[...query].js`
- Laravel API への汎用プロキシです。
- パスの安全化、GET/POST の転送、アクセス制御、監査ログ記録を行います。
- フロントから Laravel を叩く標準経路なので、API 障害時の確認優先度が高いです。

### `api/server/post.js`
- ファイルアップロードを含む記録投稿専用の API です。
- multipart 解析、編集権限チェック、Laravel への転送を担当します。
- 記録投稿・再編集の不具合調査で重要です。

### `api/token.js`
- 再検証や保護 API 呼び出しに使うトークン発行の入口です。
- 投稿後の再描画や内部 API 保護の流れを追う際に参照します。

### `api/revalidate.js`
- ISR 再検証を実行する API です。
- 投稿後にランキングページを更新させる仕組みに関わります。
