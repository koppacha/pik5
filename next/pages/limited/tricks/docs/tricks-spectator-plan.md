# 観戦モード改修計画・影響調査（2026-10-07）

ユーザー指示：limited-trickへ観戦モードを追加し、改修計画、影響調査、実装、テストを行う。

## 変更範囲と計画

- ページ入口 `index.js`（`/limited/trick`も同じ入口を利用）：観戦状態を保持し、通常モーダルとの競合を解消する。未参加・未ログインでもヘッダーから観戦できるよう参加案内の重なりを調整する。
- `TricksHud`：ナレッジ隣にfa-usersボタン、aria-pressedで状態を示す。観戦中はログを開いた状態に固定する。全モードのログ日時を日本時間のm/d hh:mmへ統一する。
- `TricksLayeredGame`：観戦移行時はコマンドを左へ収納、デッキと手札を下へスライドして画面外へ移す。DOMを保持し、ドロー・手札操作を無効にする。コマンドは閲覧目的で開閉でき、通常のコマンド開閉・手札表示設定は復帰時に維持する。
- `useTricksSpectator`：既存stateの投稿・更新ログをログID昇順のFIFOに追加する。開始以前のログは再生しない。10秒点滅、1秒待機後に次へ。同じevent_card_idならパネルを保持し、別カードではパネルを作り直す。最終処理終了後は閉じ、解除・大会切替・アンマウントでタイマーとキューを破棄する。
- `TricksSpectatorPanel` / `TricksFieldDetailPanel`：既存ランキングAPIを使用し、該当スコアと名前だけを点滅させる。投稿の点数が現在ランキングにない場合（最高記録外、後続更新など）は、投稿ログの点数と名前をパネル内に併記して点滅させる。順位を過去スコアへ置き換えない。
- プレイヤー情報：RP、DP、ホルダー数、累計数、レベル、手札数・上限の差分に対して各プレイヤーを3秒点滅させる。並列に処理し、再変化時はそのプレイヤーの期限のみ更新する。投稿者の10秒点滅と重なれば長い方の点滅を維持する。

## 影響・制約

API、DB、投稿・給付・回収ルール、認証方式には変更を加えない。stateは従来の3秒ポーリングを維持する。ランキングは自動表示中に3秒ポーリングする。同時に見えるランキングパネルは1枚とする。

APIの公開ログは最新100件のため、1回のポーリング間に100件を超える公開イベントが発生した場合や長期間非表示のタブでは、取得できなかった投稿を完全再生できない。既存通信契約の範囲の観戦機能とする。検出前に回収された切り札は公開ログのカードID・タイトルを使って表示する。キュー登録後に回収されても取り込んだ表示は完了する。

既存作業ツリーに未コミット変更があるため、それらを保持して追加する。点滅はCSS opacityのみで、毎フレームのReact更新や常時RAFを追加しない。数値変更用タイマーはプレイヤーごとに最大1つ、投稿進行用は最大1つとし、解除・破棄時に解除する。

## 検証計画

変更ファイルのNext.js lint、Playwright CLIによる架空ユーザー・APIモックのブラウザ検証を行う。実在ユーザーの認証情報やローカルDBをテストへ流用しない。

確認項目：通常表示→観戦→通常復帰、ログ日時・表示、開始前投稿の非再生、投稿と更新の順序、同一切り札パネル維持、別切り札入替、10秒/1秒/3秒の時間境界、同時数値変化、現在ランキング外の投稿スコア、途中解除と再観戦、未参加・未ログイン、スマホ幅、canvasと静止中のPhaser再描画・オブジェクト数。

## 検証結果

- Next.js lint：変更した6ファイルで警告・エラーなし。
- Playwright CLI：FIFO、同一/別切り札、10秒点滅＋1秒待機、3秒数値点滅、同時変化、途中解除、再観戦、開始前投稿の非再生、ランキング外スコアを確認。
- 追加シナリオ：未ログイン・未参加、実時間の3秒ポーリング、ツールチップ数値変化、取得前回収の投稿、0点、下位投稿のスクロール、スマホのボタン到達・パネル幅・解除、離脱を確認。
- canvasは既存構成の2枚。静止前後でPhaser再描画回数1→1、GameObject数0、Phaser sleep=true、既存の描画監視指標activeRaf=0/activeTimers=0。観戦の追加点滅はCSSで、期限付きタイマーだけを使う。
- 画像：`output/playwright/tricks-spectator-desktop.png`、`tricks-spectator-mobile.png`、`tricks-spectator-mobile-panel.png`。
- 再実行：このディレクトリで`python3 tests/run-tricks-spectator-smoke.py`と`python3 tests/run-tricks-spectator-smoke.py extra`。既定URLはlocalhost:3005、必要ならTRICKS_E2E_BASE_URLを指定する。PlaywrightスキルのCLIを使用し、専用架空ユーザーとAPIモックで実データへの書き込みを遮断する。
- DB実投稿・本番多人数接続試験は行っていない。投稿検出は既存の公開ログと3秒ポーリング契約に依存する。
