# 本番相当カードCSVの準備形式

2026-10-09。ユーザーが用意する本番相当カードCSVの推奨形式。現在の261001専用テストSeederとは別の形式であり、投入時に取込処理を対応させる。今回はデータ削除・投入を行わない。

```csv
card_key,origin_stage_id,title,rule_name,text,difficulty,creator,score_type
```

| 列 | 必須 | 内容 |
|---|---|---|
| card_key | 必須 | CSV内の一意な識別子。例prod-001。DBのidやcard_idではない |
| origin_stage_id | 必須 | 元ステージID。例203。下二桁00の特殊カードは200などを指定 |
| title | 必須 | カードに表示するステージ名。通常カードも記載し、特殊カードは固有名を記載。255文字以内 |
| rule_name | 必須 | 縛り・ルール名。255文字以内 |
| text | 必須 | カードのルール本文。カンマ・改行を含む場合はダブルクォートで囲む |
| difficulty | 必須 | 難易度1〜5の整数 |
| creator | 任意 | 表示する考案者名をそのまま記載。例：Alice / Bob。ユーザーIDやスクリーンネームへの変換は行わない。未設定は空欄 |
| score_type | 必須 | pointsまたはtime。timeの投稿値は整数秒。元ステージ419〜428は残り時間が多いほど上位、それ以外は短いほど上位 |

任意のcreatorもヘッダーには含め、未設定の行だけ空欄にする。UTF-8、カンマ区切り、ヘッダーあり。BOMなし推奨。値のダブルクォートは二重にする。

DBのid、card_id、投稿用stage_id、state、rarity、rewards、count、taker、期限、日時、大会紐付けは取込・大会初期化・ゲーム進行が管理するためCSVへ含めない。大会ID・開始終了時刻はカードCSVとは別に指定する。

現行の大会初期化は160枚を選ぶ。今回1大会分を用意するなら160行が基本で、160枚未満では初期化できない。候補プールを160枚より多くする場合は選択方針を別途指定する。

既存テストSeederは6列固定、261001用card_key、考案者固定、score_type取込なしで、元ステージIDが全てstagesに存在することを要求する。この8列CSVはそのまま既存Seederには投入できない。投入処理ではscore_type・creatorの取込と、下二桁00の特殊元IDの検証例外を対応する。通常の元ステージIDの実在検査は維持する。
