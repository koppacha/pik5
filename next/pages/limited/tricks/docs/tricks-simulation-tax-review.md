> **廃止済み（2026-07-18）**：本書のドロー税は後続の仕様変更で廃止された。時間経過によるレア度補正のみ現行シミュレーターへ引き継いでいる。以下は検討履歴として保持する。

## 1. 試験パラメータ

- `a = 27P`
  - 既存2回の最終保有ポイント32件における第3四分位数（Q3）を採用した。
  - 上位25%程度の保有者を課税対象とする意図である。
- `b = 5P`
  - 既存分布の四分位範囲は`Q3 - Q1 = 27 - 8 = 19P`。
  - これを4段階へ分け、`ceil(19 / 4) = 5P`を1税区分とした。超過分への限界負担は20%となる。
- `n = 60分`
  - 47時間目を最後の補正タイミングにするため、1時間単位で47回補正する。
- `m = 90 / 47 ≒ 1.914893617%ポイント`
  - ★2以上を初期10%から47時間目の100%まで線形増加させる。
  - `10 + 47 × (90 / 47) = 100%`。

## 2. 実装内容

- ドロー税はドロー直前の保有ポイント`P`から`floor(max(0, P - 27) / 5)`で計算し、基本ドロー費1Pと同時に徴収する。
- 徴収税はプレイヤーごとの未還流税として累積し、次回テイク時に実カード枚数とは別のスタック加算値として全額移管する。
- レア度補正は経過時間の完了済み1時間数を用い、47時間以降は★2以上100%で固定する。
- ★2〜5の比率`6 : 3 : 0.9 : 0.1`は維持する。
- 概要JSONへ施策値、徴収・還流・未還流税、レア度別ドロー数を追加した。
- 税境界、初期レア率、47時間ピーク、レア度内訳維持の固定テストを追加した。

## 4. 妥当性レビュー

- 同一seed比較では最終総ポイントが332Pから314Pへ18P（5.4%）減少した。
- ただし税の徴収は4P、終了時点の未還流は2Pだけである。総ポイント減少の大部分は、高レア化による投稿費増加と、それに伴う行動変化によるものと考えられる。
- 最大保有ポイントは55Pから58Pへ増加した。2回目も最大62Pであり、上位者のポイントインフレ抑制効果は確認できない。
- `a=27`かつ`b=5`では、最初の1P課税が発生するのはドロー直前に32P以上ある場合である。ドロー時点でこの条件を満たす機会が少なく、税制はほぼ発動しなかった。
- 徴収税はスタックへ還流し、さらに難易度ボーナスの基礎へ含まれるため、回収時には徴収額以上のポイントを生む可能性がある。税単体では通貨消滅策にならない。
- 47時間目に★2以上100%とする補正は、終盤の投稿費を大きく引き上げる。2回目では初投稿数と総ランクポイントが大幅に低く、参加行動を抑制する副作用が疑われる。

## 5. 結論

本施策は実装上の整合性を満たすが、現状値のまま大会ルールへ採用することは推奨しない。総ポイントは減少したものの、税の寄与は小さく、最大保有量の抑制にも成功していない。レア度補正の影響が強すぎるため、次回検証では税制とレア度補正を分離したA/B比較が必要である。
