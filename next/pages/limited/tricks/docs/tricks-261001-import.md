# テスト大会261001のCSV投入手順

大会261001と初期デッキ160枚を、同じCSVからローカル・本番の各DBへ作成する。CSVは専用のサンプルデータだけを含み、ユーザーアカウント・認証情報・投稿履歴は含まない。

## ファイル

- 大会設定：`laravel/database/seeders/data/tricks_261001_event.csv`
- カード設定：`laravel/database/seeders/data/tricks_261001_cards.csv`
- Seeder：`laravel/database/seeders/TrickStaging261001Seeder.php`

大会の開始は2026-10-01 20:00、終了は2026-10-06 22:00（ともにJST）。通常の時計と認証で進行し、専用のサンプルカード160枚を使用する。各難易度32枚。カードのレア度は未確定・draw_count=0で開始する。

`card_key`はCSV内の識別子。DBの主キーや投稿用stage_idは環境ごとに割り当てるため、ローカルのIDや共有ステージを上書きしない。カード名・元ステージID・ルール本文・難易度はCSVから読み込む。

## 投入

Tricks関連の現行マイグレーションと参照元ステージ（201〜230、301〜350、401〜422）が入っている環境に、SeederとCSV2点を配置する。既存アプリと同じLaravelコンテナで実行する。

```bash
docker compose exec -T laravel php artisan db:seed --class=TrickStaging261001Seeder --force
```

本番にも同じコマンドで投入できる。今回の作業ではローカルへ投入済み。本番への投入は実施していない。

SeederはCSVヘッダー・大会1行・カード160行・card_key重複・日程・難易度・参照元ステージの存在を検証する。初期化はトランザクション内で行い、対象の専用カードIDだけを使う。

再実行時、正常に初期化済みの261001はカードや参加・投稿状態を保持する。開催前／開催中でCSVより終了日時が短ければ期間だけ延長する。終了済み大会を再開せず、不完全な既存データは上書きせず停止する。

## 確認

- `/limited/tricks?261001` または `/limited/trick?261001` へアクセスする。
- 初期状態はデッキ160枚・捨て札0枚・参加者0人。未ログイン時はログイン導線を表示する。
- 開催時間内はログインして参加できる。終了後は大会結果を表示する。
- トップページの案内は「トリックテイキング制×スタンダード」を表示する。

環境がテスト大会のパスワード公開設定を有効にしている場合は、既存の参加パスワード保護も適用される。
