# 低残高プレイヤーの無料初投稿時1P即時給付 比較

## 結論

即時1P給付は、5P以下への30分定期給付だけの場合と比べて、下位層の活動中平均残高と終了時残高を小幅に改善した。初投稿と最終ランクPも増えたため、無料初投稿への参加を促す効果は認められる。

一方、活動中2P未満率は実質的に変わらず、更新・ドロー・テイクの増加も参考95%区間が0をまたぐ。難易度Pを必要とする次の有料行動まで確実につなぐ制度としては弱い。主制度ではなく、定期給付に加える軽量な参加報酬としての試行が妥当である。

## 比較条件

- C案：非テイカー初投稿無料、テイカー初投稿と更新は難易度P、総還元`スタック数 + 実支払いP`と改案順位配分
- C案＋5P以下30分給付：参加済みで、JST毎時00分・30分の判定時に所持Pが5P以下なら1P給付
- 即時給付案：上記に加え、判定時点で5P以下のプレイヤーが非テイカーとして各場札への初投稿を完了した直後に1P給付
- 即時給付後も残高が5P以下なら、次の00分・30分給付を通常どおり受けられる
- 同一seed 283000〜283099、100大会×3条件
- 下位層は各seedの「C案＋5P以下30分給付」で最終ランクP下位4人を選び、同じプレイヤーを3条件で追跡
- 残高率は30分スナップショットのうち本人の活動中だけを集計

既存シミュレーターの給付資格は、空場時の`所持P + 手札枚数 < 8`または一回給付フラグである。今回の比較ではユーザー提示条件を優先し、5P以下なら場札・手札状態にかかわらず定期給付対象とした。最初のC案列は従来の給付資格のままであり、後二列の直接比較が今回の主比較である。

即時給付案では16.43P/大会を投稿直後に配る一方、受給者が5Pを超える場面が増えるため、次回以降の定期給付は9.94P/大会減った。給付総量の純増は6.49P/大会で、即時給付の39.5%に相当する。即時給付を足しても定期給付を完全には置き換えないため、終了時総残高は7.05P/大会増えた。

## 判定

- **資金繰り**：小幅改善。活動中平均残高は+0.191P、終了残高は+0.748P
- **困窮状態の解消**：追加効果はほぼなし。30分給付だけで0P率が0%になり、即時給付による2P未満率の差も不明確
- **再参加**：初投稿は+0.255回で増加。無料投稿への直接報酬としては機能した
- **次の有料行動**：更新、ドロー、テイクはいずれも増加方向だが、明確な差とはいえない
- **発行量**：30分給付単独より+6.49P/大会。二重受給を許しても、即時給付の多くは後続の定期給付減少で相殺される

採用する場合は、まずこのままの1P・残高5P以下・各場札1回を候補とする。2P以上へ増額すると難易度1〜2の有料行動を直接賄いやすい一方、投稿目的の巡回と発行量が増えるため、次の比較対象にするべきである。
