# 13人参加時の山札枚数と同時枯渇

## 条件

- 基礎シミュレーターを13人・48時間・現行の活動モデルとポイント仕様で実行した
- 初期山札だけを変更し、`310000`〜`310299`の300シードを枚数ごとに試行した
- 山札と捨て札の両方が0枚で、正の時間が経過した区間を同時枯渇と数えた。同一時刻内の一瞬の0枚は含めない
- 全試行で不変条件エラーは0件だった

## 結果

| 初期山札 | 同時枯渇した試行 / 300 | 枯渇区間数 | 利用可能カードの最小値 |
| ---: | ---: | ---: | ---: |
| 145 | 15 | 18 | 0 |
| 150 | 5 | 5 | 0 |
| 155 | 3 | 3 | 0 |
| 156 | 4 | 4 | 0 |
| 157 | 1 | 1 | 0 |
| 158 | 1 | 2 | 0 |
| 159 | 1 | 1 | 0 |
| 160 | 0 | 0 | 1 |
| 165 | 0 | 0 | 3 |
| 170 | 0 | 0 | 15 |

この試行群では160枚が同時枯渇を起こさなかった最小の検証枚数だった。ただし最少残数は1枚で、余裕はほぼない。

別の`310300`〜`310599`の300シードで再検証した結果は以下のとおり。いずれも同時枯渇0件、不変条件エラー0件だった。

| 初期山札 | 同時枯渇した試行 / 300 | 利用可能カードの最小値 |
| ---: | ---: | ---: |
| 160 | 0 | 3 |
| 170 | 0 | 2 |
| 180 | 0 | 13 |

160枚は計600試行で0件だが、最少1枚まで接近した。170枚も別シードでは最少2枚だった。**減数するなら180枚**を現時点の推奨候補とする。200枚から20枚減らしつつ、検証した範囲では最少13枚を維持した。乱数試行で0件だったことは無発生の保証ではない。正式ルールの200枚は現時点で変更しない。
