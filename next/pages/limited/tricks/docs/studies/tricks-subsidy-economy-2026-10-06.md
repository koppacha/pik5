# 2026-10-06 給付条件変更のドローポイント経済評価

本体の改修前に新旧条件を同一seedで比較した。試行範囲では新条件によるインフレの兆候はなく、実装へ進めると判断した。

## 判定条件とモデル

- 旧：空場かつ手札+P<8の定期給付、テイク・自然回収1位・返却の次回一回給付。
- 新：切り札を問わず手札+P<3の定期給付、行動直前の手札+P<5でテイク・無料初投稿が成功すると即時1P。テイクは消費前の手札を含める。
- 参加時5P、後発参加ボーナス、空場の全員3資源緊急補充、レア度還元、ポット・課税・返却費、投稿負債は共通。初期人数13人・活動時間・性格・スコアモデルも共通。
- 両条件でデッキ全体の均等抽選を使う。以前のシミュレーターに残っていた難易度先行抽選を修正し、捨て札からの即時再循環・レア度再抽選も本体へ合わせた。
- 通常48時間・160枚をseed306000〜306099の100組、デッキ24枚・48時間と160枚・240時間をseed307000〜307019の各20組、合計140組・280大会で比較。
- インフレ判定は給付総量、時間推移を含むドローポイント在庫、終了残高、個人最大残高を比較し、カード循環と消費量も確認する。増額があっても無条件に許容する閾値は設けない。

終了残高差は-13.61P（対応ありの参考95%区間-17.83〜-9.39P）。総支出は437.03→430.96Pで約1.4%減、回収枚数差は+0.48枚（参考95%区間-0.22〜+1.18枚）。資金供給を抑えつつ、モデル上の循環は概ね維持されている。

|ストレス条件|旧終了残高|新終了残高|旧全給付|新全給付|
|---|---:|---:|---:|---:|
|24枚・48時間|154.75P|139.15P|34.20P|16.90P|
|160枚・240時間|148.55P|126.75P|74.25P|46.20P|

10日開催の最終24時間の残高+ポットは各試行とも一定（平均162.00→132.55P）。新条件で無活動の長期給付が積み上がる現象は見られなかった。全280大会で不変条件違反0。通常200大会で既存固定テスト失敗0。追加した新条件境界テストと実装の回帰テストは別途実行する。

即時支給は判定前合計が5未満なので、無料初投稿だけで合計5以上へ支給を積み上げられない。削除・再投稿の再支給を禁止するため、無償の繰り返し発行も防ぐ。

## 再現とデータ

- [大会別比較CSV](tricks-subsidy-economy-2026-10-06.csv)：280行。アプリDBや実在ユーザーの情報は使っていない。
- [比較スクリプト](tricks-subsidy-comparison.py)：Python標準ライブラリのみ。

リポジトリルートで次を実行する。

```bash
python3 next/pages/limited/tricks/docs/studies/tricks-subsidy-comparison.py --output /tmp/tricks-subsidy-comparison.json
```

通常シミュレーターの既定は `--subsidy-policy low_resources`。旧条件は `--subsidy-policy legacy` で再現できる。

これは13人の既存行動モデルの評価であり、実参加人数や行動が異なる大会すべての残高を保証するものではない。10日比較は既存の活動時間設定を維持した長期の滞留検証であり、10日間毎日長時間参加する負荷モデルではない。
