# 投稿費・ポイント還元改案の比較

この2ケース比較は、後続の[4ケース比較](tricks-point-four-case-report.md)へ拡張済み。数式の詳細は本書、最新の比較結果は4ケース比較を正とする。

## 結論

提示された改案をそのまま採用しても、下位プレイヤーの大会中の資金繰りは改善しなかった。

現行ルールで最終ランクPが下位4人だったプレイヤーを、同一seedの改案でも追跡した。100大会の平均では、終了時残高は8.67Pから9.45Pへ0.78P増えた一方、活動中平均残高は5.47Pから4.17Pへ1.30P減った。活動中に0P以下だった割合は1.64%から5.96%、2P未満だった割合は6.52%から13.31%へ増えた。

終了時のPと手札は効用0という大会ルールなので、終了残高の増加より大会中に支払える状態かを重視すると、資金繰りは悪化と判定する。

## 数式化

場札のスタック数を`S`、投稿・任意延長による実支払い総数を`C`、投稿参加者数を`n`とする。総還元ポイント`Q`は次のとおり。

`Q = 0 (n=0)、Q = S + C (n>=1)`

厳密な順位だけがある場合、順位`i`の配分を`x_i(Q,n)`とする。提示された下限配分は次の基底ベクトル`b(n)`で表せる。

- `b(1) = (4)`
- `b(2) = (3,2)`
- `b(3) = (4,2,0)`
- `b(4) = (4,2,1,0)`
- `n>=5`では`b(n) = (3,2,2,1,...,1,0)`。1Pは`n-4`個

いずれも成分和は`n+3`。`Q=n+3`なら`x(Q,n)=b(n)`とする。

`Q>n+3`の1Pごとの再帰は以下で定義できる。最下位`x_n`は固定する。上から数えた順位`i`に必要な直上との差を`d_2=2`、`d_i=1 (3<=i<=n-1)`とする。

1. `J={i | 2<=i<=n-1, x_(i-1)-x_i>d_i}`を求める。
2. `J`が空でなければ、最小の`i`について`x_i`を1増やす。
3. `J`が空なら`x_1`を1増やす。
4. 総和が`Q`になるまで繰り返す。

4人では次の列になる。

`7:(4,2,1,0) → 8:(5,2,1,0) → 9:(5,3,1,0) → 10:(5,3,2,0) → 11:(6,3,2,0) → 12:(6,4,2,0) → 13:(6,4,3,0)`

ユーザー例の最後の`{12:6,4,3,0}`は成分和が13なので、`{13:6,4,3,0}`として扱った。

## 仕様上の矛盾と比較時の扱い

現行のテイク必要手札は初回2枚なので、全員の初投稿費が最低1Pとなっても`S+C`は`n+2`になり得る。従って、現行仕様のままでは理論下限を常に`n+3`とはできない。比較では`Q<n+3`の場合、基底ベクトルの最下位に近い正の成分から1Pずつ減らした。改案ではこのケースが1大会平均2.65場札発生した。

また、5人以上の提示基底`(3,2,2,1,...,0)`は1位と2位の差が1Pなので、「常に2P以上」と矛盾する。提示例を優先して比較した。一貫した別案は、`n>=3`について`(4,2,1,...,1,0)`を基底にすること。成分和は同じ`n+3`で、首位差2Pを守れるが、今回の比較には使用していない。

同順位の規則も別途必要になる。比較モデルのスコアは連続値で同点が実質発生しない。実運用では、同順位者が占める順位枠の配分を合計して人数で割る方法を推奨する。同順位同配分と整数Pを両立するなら、割り切れない端数は次回回収または給付原資へ繰り越す必要がある。

## 比較条件

- 48時間、16人、山札200枚、同一seed 281000〜281099の100大会
- 現行の参加時刻、活動時間、スキル、行動モデル、給付、返却、任意延長、平方根レベル式、クールダウンを維持
- 現行：非テイカー初投稿0P、テイカー初投稿と全員の更新は難易度P。現行の控除・難易度ボーナス・順位配分
- 改案：非テイカー初投稿1P、テイカー初投稿と全員の更新は難易度P。総還元`S+C`と上記順位配分
- 下位層は各seedの現行結果で最終ランクP下位4人を固定し、同じプレイヤーを改案でも集計した。改案側の結果から下位を選び直していない
- 活動中残高は30分スナップショットのうち本人が活動時間内だった時点だけを集計

| 指標 | 現行 | 改案 | 差 |
|---|---:|---:|---:|
| 投稿費 | 145.02P | 297.56P | +152.54P |
| 回収還元 | 288.95P | 536.24P | +247.29P |
| 給付 | 102.65P | 80.42P | -22.23P |
| 終了時総残高 | 163.87P | 230.09P | +66.22P |

改案は回収時に原資を100%返すため大会全体のPを増やすわけではないが、現行の控除を廃止することで既払ドロー費を含むスタック分がより多く戻り、給付を除く循環資金が増えた。一方、下位層は無料だった初投稿を先払いする。還元までの待ち時間があるため、終了残高が増えても途中の流動性は悪化した。

## 判定と修正候補

改案の順位配分は、現行の1位偏重を緩和する方向として妥当。しかし、全非テイカーから初投稿時に1Pを取る変更を同時に入れると、下位層の流動性改善にはならない。

次の比較候補は「非テイカー初投稿1Pを徴収するが、回収を待たず初投稿完了時に1Pの参加クレジットを付ける」方式。会計上は初投稿無料と同じなので、単に課金表示を増やす意味は薄い。目的が無投稿や乱参加の抑制なら、無料枠をプレイヤーごとに一定時間1回とする方が目的に直接対応する。

より単純な推奨案は、非テイカー初投稿を現行どおり無料に保ち、総還元`S+C`と新順位配分だけを比較すること。順位配分改善と参加費変更を分離できる。これにより下位への還元が増えるか、1位偏重がどこまで減るかを次段階で確認する。

## 検証

200大会すべてで既存不変条件違反0、回収配分合計と総還元の不一致0。4人の7〜13P列は上記例と一致した。シミュレーションは行動仮定に依存し、実利用を保証しない。
