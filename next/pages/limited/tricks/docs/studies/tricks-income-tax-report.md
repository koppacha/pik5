# 定期給付時の高残高課税 q・t 最適化

## 結論

現在のシミュレーターと「下位層への還元を重視する」という目的では、推奨値は次となる。

> **`q = 18P`、`t = 1P`**

通常合理行動者への課税を参加者の5%以内、通常流量の0.5%以内へ抑える制約を置き、その中で流量回復、2P未満状態の解消、5P以下への到達、貯め込みXへの再還流抑制を評価した結果である。

この施策は貯め込みによる流動性悪化を緩和するが、完全には解消しない。通常時との差に対し、総支出は21.0%、他15人の2P未満率は61.2%を回復した。既存順位配分へポットを加える構造上、税の10.8%はXへ戻り、5P以下へ届く割合も59.7%に留まる。

## 課税とポットのモデル

毎時00分・30分の通常給付処理後、参加済みプレイヤー`i`の残高を`P_i`として、

```text
tax_i = t  if P_i >= q
        0  otherwise
P_i' = P_i - tax_i
pot' = pot + Σ tax_i
```

とする。`t < q`を候補条件とするため残高は負にならない。投稿者がいる次の場札回収時に、

```text
total_reward' = existing_total_reward + pot
pot = 0
```

とし、既存の順位配分で全額を配る。投稿者0人の回収ではポットを保持する。大会終了時の強制回収も「次の回収」に含める。

## 最適化式

### 1. 通常プレイヤー保護制約

通常合理行動条件を`R`、貯め込みX条件を`H`とする。候補 `(q,t)` は次をすべて満たすものに限定する。

```text
I_R(q,t) = E[課税された人数] / N              <= α = 5%
B_R(q,t) = E[徴税P] / E[通常時の総支出P]       <= γ = 0.5%
U_R(q,t) - U_R(0,0)                           <= ε = 0.25pt
```

`U`はX以外の活動中2P未満率。通常プレイヤーの誤課税人数、経済規模に対する税負担、低残高率の悪化を上限管理する。

### 2. 便益の正規化

```text
F(q,t) = clamp((S_H(q,t) - S_H(0,0)) / (S_R(0,0) - S_H(0,0)), 0, 1)
D(q,t) = clamp((U_H(0,0) - U_H(q,t)) / (U_H(0,0) - U_R(0,0)), 0, 1)
L(q,t) = 5P以下の受給者へ配られたポットP / 徴税P
A(q,t) = 1 - Xへ再配分されたポットP / 徴税P
```

- `F`：失われた通常ポイント流量の回復率
- `D`：貯め込みで増えた2P未満率の解消率
- `L`：給付対象相当の低残高層への到達率
- `A`：貯め込みXへの再還流を避けた割合

### 3. 目的関数

```text
J(q,t) = 0.25 F(q,t) + 0.35 D(q,t) + 0.25 L(q,t) + 0.15 A(q,t)

(q*,t*) = argmax J(q,t)
           subject to I_R <= 5%, B_R <= 0.5%, ΔU_R <= 0.25pt
```

流量回復25%、困窮状態の解消35%、低残高層への到達25%、再吸収抑制15%とし、「流動性と同時に下位層還元」を目的の60%へ置いた。この重みは運営方針であり、数学的に唯一ではない。

## 探索と較正

### 分位点からの初期候補

通常合理行動者1,600人・大会の個人瞬間最大残高は95%点が20Pだった。通常者の95%を保護する初期閾値は、課税条件が`P >= q`であるため、

```text
q_0 = 1 + Q95(通常合理行動者の大会内最大残高) = 21P
```

となる。貯め込みXが21P以上にいる区間の30分正味流入は90%点が4Pだったため、流入の9割を次回判定で相殺する初期税額は、

```text
t_0 = ceil(Q90(30分正味正流入 | P >= q_0)) = 4P
```

となる。したがって、分位点だけなら`q=21,t=4`が初期案である。

## セルフレビュー

1. **目的関数の重みは運営判断**
   - 下位層関連へ60%を置いたため`q=18,t=1`になった。通常者保護を強くすれば`q=21,t=4`が選ばれうる。「唯一の数学的最適値」ではない。

2. **これは所得税ではなく残高税**
   - 新たに得た所得でなく、判定時残高へ課税する。名称とプレイヤーの直感がずれる。

3. **下位層への還元は保証されない**
   - 既存順位配分へポットを合算するため、上位者や納税者が再取得できる。推奨値でも10.8%がXへ戻り、5P以下への到達は59.7%。`q,t`だけでは100%の下位還元を実現できない。

4. **流量は部分回復に留まる**
   - 総支出差の回復は21.0%。税はXにドローやテイクを行わせず、場札作成不足を直接解消しない。

5. **30分境界を狙った回避が可能**
   - 判定直前にポイントをカードや有料行動へ変えれば課税を避けられる。これは流動性を生む面もあるが、不要なドローや形式的支出を誘発しうる。

6. **大会終了直前の還元は次回課税されない**
   - 終了時強制回収は最後の定期判定後なので、最終還元を貯め込める。大会終了後の流動性には影響しないが、最終残高指標は高く残る。

7. **分布変化ごとの再較正が必要**
   - 参加人数、難易度、給付、投稿費、還元式、開催時間が変わると`q,t`も変わる。直近大会またはシミュレーションで四半期ごと・ルール変更ごとに再計算するべきである。

## 実運用案

仮導入するなら`q=18,t=1`で開始し、次を監視する。

- 通常行動者の課税人数率が5%を超えたら`q`を1上げる
- 通常税負担率が総支出の0.5%を超えたら`q`を1上げる
- 貯め込み疑い条件で2P未満率の解消が50%未満なら`t`を1上げる
- X相当の高残高者への再還流が15%を超えたら、`t`ではなくポット配分規則を見直す

下位層への到達を保証したい場合は、ポットを既存順位配分へ混ぜず、「回収参加者のうち残高5P以下へ先に均等配分し、余りだけ通常配分」とする別ルールが必要である。
