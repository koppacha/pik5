# 動的徴収・Pot・投稿負債・手札上限の流動性評価

## 条件

- 基礎シミュレーター既定値、16人、48時間、200枚
- 同一100 seed（287000〜287099）による対応比較
- 通常行動と、実力1位Xが期待収支の正の無料初投稿以外を避けてポイントを貯め込むストレス条件を評価
- 旧条件は投稿時の負債なし、徴収・Potなし、動的手札上限なし
- 新条件は投稿費のみ負債可、`残高 > (L+2)×5`なら各給付スロット1P徴収、徴収・返却費を次回収へ移転、手札上限`(L+2)×3`

通常条件では総消費が9.36P（2.00%）、総ランクPが12.45（0.84%）増え、活動中2P未満率は全員で0.27ポイント、他15人で0.22ポイント低下した。一方、他15人の活動中平均残高は0.123P下がり、負数率が0.71%発生した。

X貯め込み条件では総消費が36.58P（9.45%）、回収数が1.78、ドローが22.13、投稿が7.73、総ランクPが25.73増えた。旧通常条件から旧貯め込み条件で失われた総消費81.38Pのうち45.0%を回復した。Xの参加後平均残高は58.3%、終了残高は53.4%減り、他15人の活動中平均残高は1.087P増え、2P未満率は3.55ポイント低下した。

Pot流入は通常35.71P、貯め込み時87.58Pで、いずれも大会終了までに100%再分配された。貯め込み時のPotの92.9%は定期徴収、7.1%は返却費だった。Potを次回収へ全額移す仕組みは、滞留在庫を実際の投稿・ドロー・テイクへ戻している。

## セルフレビュー

- 流動性は改善した。特に意図的な貯め込みに対し、消費減少の45.0%を回復し、他プレイヤーの低残高状態も減らした
- 通常条件では低残高率と総消費は小幅改善したが、平均残高はわずかに低下した。投稿負債による活動中負数率は約0.7%で、UIには支払後残高の明示が必要である
- Potは既存順位配分へ合算するため、下位層への到達を保証しない。この試験で確認できるのは市場全体とX以外の平均的な改善であり、個々の下位順位への公平性ではない
- 手札上限は初期6枚だが、今回の行動モデルでは手札在庫が平均的にそこまで増えず、主要な改善要因は徴収・Potと投稿負債である。上限は暴走防止として有効でも、今回の流量改善への寄与は限定的とみられる
- 税閾値はレベル上昇で10P、15P、20Pと増えるため、テイクしない貯め込みXには強く、継続的にテイクする競技参加者には緩い。この競技行動との整合性は狙いどおりだが、レベル上げを節税目的に選ぶ戦略が生じないかは別途検証余地がある
