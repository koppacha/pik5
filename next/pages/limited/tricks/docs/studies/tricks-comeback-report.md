# C案・再挑戦チケット・15分給付の比較

## 結論

100seed・各3条件、合計300大会では、再挑戦チケットも15分給付も、下位層の資金繰りを明確には改善しなかった。

- チケット：活動中平均残高は+0.07Pで差を確認できず、0P以下率と2P未満率も改善しなかった。初投稿とランクPは増えたが、更新数は増えなかった
- 15分給付：活動中平均残高は+0.18Pと小幅に改善したが、0P以下率・2P未満率・更新・テイクの改善は確認できなかった

15分給付は3条件の中では資金繰りに最も近い効果を示すが、実用上の改善は弱い。チケットは発行後の利用条件が狭く、下位層本人の利用率が低すぎた。

## 比較条件

- C案：非テイカー初投稿無料、テイカー初投稿と更新は難易度P、総還元`S+C`と改案順位配分
- チケット：C案に再挑戦チケットを追加
- 15分給付：C案の給付条件は変えず、給付判定間隔を30分から15分へ変更
- 同一seed 282000〜282099、100大会×3条件
- 下位層は各seedのC案で最終ランクP下位4人を選び、同じプレイヤーを他条件でも追跡
- 30分スナップショットで本人の活動中だけを残高集計

15分案は、テイク・自然回収1位・返却による一回給付と、空場時の継続給付の判定スロットを15分へ短縮したもの。給付資格自体は拡張していない。スナップショット間隔は比較のため30分を維持した。

## チケット条件

- 投稿者3人以上の場札で下位半分
- 回収・還元後の残高5P以下
- 保有上限1枚、前回発行から120分以上
- 6時間または大会終了で失効
- 他者テイク札で無料初投稿後の最初の更新だけ無料
- 免除額は実支払いPおよび総還元`S+C`の`C`へ含めない
- 自己ベストを更新して投稿が成立したときだけ消費

チケットの大会全体利用率は31.2%。C案基準の下位4人に限ると1人平均0.468枚発行、0.050枚利用で、発行分の約10.7%しか使われなかった。6時間以内に他者札へ初投稿し、さらに最初の更新で自己ベストを更新する条件まで到達しにくい。初投稿は増えたが、目的だった更新増加にはつながらなかった。

15分給付の給付量はC案比で大会あたり+2.13Pに留まった。一回給付フラグは支払後に消費され、空場時だけ継続給付されるため、判定回数を2倍にしても支給量は2倍にならない。

## 判定と次案

- 現行のチケット案：不採用。発行対象より利用条件がボトルネック
- 15分給付：小幅な残高改善はあるが、再参加行動の増加がなく、単独採用の根拠は弱い

チケットを再検討するなら、有効期限を延ばすより用途を広げる方が直接的である。次候補は「下位・5P以下で1枚、次の他者場札への初投稿完了時に1Pを即時付与、または次のドロー1回を無料」のいずれか。前者は給付目的の巡回、後者はカード蓄積へ流用されるため、別々に比較する。

定期給付を改善するなら、全スロットを15分化するより「5P以下の活動者が有効な初投稿を完了したとき、次の給付を待たず1Pだけ前倒しし、その後30分は通常給付しない」方式の方が、総発行量を増やさず必要時刻へ寄せられる。

## 検証・再現
