# テイクルール変更案の単独・併用比較（2026-09-28）

## 比較条件

- `lab/tricks_rule_simulation.py` の現行設定を基準に、同一100シード（312000〜312099）、13人・48時間で各案を**１項目ずつ**変更した。併用案も参考として計算した。計500大会。
- 60分案はテイク成功後のクールダウンだけを90→60分にし、全場札１位解除と終了150分前からの免除は維持した。
- 全場札１位解除の廃止案はその解除だけを外し、90分制限と終了150分前からの免除を維持した。
- レア度案は初期排出率を1〜5で87/8/4/0.9/0.1%に変更した。既存の「レア合計が46時間目に100%まで指数増加し、レア度2〜5の比率を維持する」時間変化は維持した。テイク時の**実カード枚数**は変えず、レア度1は0、レア度2〜5は`floor(実スタック枚数 / 3) + {1,4,7,15}`Pを回収原資のスタック値へ加えた。順位P、必要手札数、山札の枚数は変えない。投稿判断で参照する予想還元額にも反映した。
- 各案は検討用の比較スクリプトで適用し、ゲーム本体・正式ルールは変更していない。

## 補助指標と読み方

### 枯渇率と場札上限の時間率

「枯渇」は山札と捨て札が同時に0枚になる状態。「動的上限到達」は場札数がその時点の`min(max(1,累計参加者数-1),16)`に等しい状態。時間率はいずれも大会全体48時間を分母とし、場札数・参加人数の変化をイベント時刻で積算した。枯渇大会率は100大会中の発生割合。

- 60分案ではテイク数が約8.1%増え、回収と投稿の機会も増えた。個人最多テイクは平均+1.27回。
- 全場札１位解除の廃止では平均3.05回テイクが減った。単独変更のランクP差は約0.7%で、競技結果への影響は小さい。
- レア度案の主効果は通常Pの増加で、回収還元が約23.5%増え、給付が約15.4%減った。ボーナス62.71Pはテイク時に設定された総量であり、未投稿のまま終了した札なども含むため、実際に還元された追加額とは一致しない。ランクPとテイク数は大きくは変わらない。
- ３案併用の差は単独差の単純合計にはならない。資金、手札、投稿先の選択が変わるためである。
- 山札＋捨て札の枯渇時間は全条件平均0分。不変条件違反は計500大会で0件。小さい差には乱数変動が含まれるため、採用判断の際は方向性を中心に読む。
