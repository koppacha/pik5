# 有料更新判断の合理性監査

## 結論

従来の有料更新判断には修正が必要だった。支払可能で自己ベスト更新の可能性があれば更新候補になり、執着・ホルダー優先・ランクP効率の分岐が、ランクP増分に対して費用対効果の悪い候補も選んでいた。試行後も自己ベストが少し上がれば、順位見込みが変わらなくても難易度Pを支払っていた。

100大会では、従来判断で成立した有料更新の54.46%が、将来の参加者を含む予測でもランクP増分0だった。パーソナリティ別でも51.73〜56.98%であり、特定の個性ではなく共通判断の問題だった。

## 修正した判断

有料更新の共通目的を、最終ポイント残高ではなく期待ランクPの増加とした。ポイントは勝利得点へ加算せず、将来のドロー・投稿を可能にする流動性として扱う。

更新開始時に、現在スコアを維持した場合と更新後の期待スコアを投稿した場合について、将来参加者を含む予測順位からランクP差`ΔR`を計算する。費用を`C`、所要時間を`T`分として、次をすべて満たす場合だけ試行する。

1. `ΔR > 0`
2. `ΔR / C >= 0.5`（無料更新は常に費用条件を満たす）
3. `ΔR > T / 60`（1時間あたり1ランクP超）

試行後は実際の候補スコアでも再計算し、`ΔR > 0`かつ`ΔR / C >= 0.5`を満たさなければ投稿せず、ポイントも支払わない。所要時間はすでに費やしたため、完了時の再判定では埋没費用として除外する。

各パーソナリティの選好は、この共通条件を通った候補の選択にだけ適用する。ホルダー優先と執着の固定的な大幅加点を廃止し、ランクP評価への小さな選好加点へ変更した。比較再現用に`paid_update_policy=legacy`を残し、既定値を`rank_point_roi`とした。

## 100大会比較

同一seed 284000〜284099で、従来判断と修正版を各100大会実行した。

| 指標 | 従来判断 | 修正版 |
|---|---:|---:|
| 有料更新／人 | 4.636 | 2.036 |
| 更新支払いP／人 | 6.473P | 2.851P |
| 期待ランクP増分／更新 | 1.021 | 3.060 |
| 期待ランクP増分／支払い1P | 0.731 | 2.185 |
| ランクP増分0の有料更新率 | 54.46% | 0.00% |
| 最低ポイントROI未満の有料更新率 | 55.62% | 0.00% |
| 回収数／大会 | 53.28 | 61.59 |
| 投稿費／大会 | 144.17P | 103.27P |
| 確定ランクP／大会 | 797.93 | 1433.81 |
| 終了時総残高／大会 | 163.59P | 170.66P |

修正版は更新回数を56.1%減らしたが、期待ランクP増分は1人あたり4.734から6.229へ増えた。費用対効果の低い再試行へ使っていた活動時間が初投稿や次の場札へ移り、回収数は+8.31、確定ランクPは+635.88となった。確定ランクPは参加者数と回収数でも増えるため、個別更新だけの効果ではなく大会循環の改善を含む。

修正版では全パーソナリティで増分0・最低ROI未満の支払いは0件だった。更新回数の水準と他行動の選び方には個性が残り、全タイプで平均ランクPが増加した。

## 瞬間最大ポイント

ポイントが変動する全イベント直後に個人別最大残高を更新し、各大会で最も高かった個人残高を集計した。30分スナップショットによる近似ではない。

| 大会別の個人瞬間最大残高 | 従来判断 | 修正版（現在） |
|---|---:|---:|
| 100大会平均 | 23.59P | **21.70P** |
| 中央値 | 22P | 21P |
| 95パーセンタイル | 36.05P | 28P |
| 100大会中の最大 | 47P | **34P** |
| 100大会中の最小 | 15P | 15P |

修正版の大会別最大残高平均は21.70P、観測最大は34P。従来比では平均-1.89Pで、参考95%区間は`-3.307〜-0.473P`だった。合理化によって更新費が減っても、ポイントの貯め込みは増えず、高残高の裾が短くなった。
