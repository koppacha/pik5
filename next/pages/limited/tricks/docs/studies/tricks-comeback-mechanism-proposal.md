# 下位層の再参加を促す仕組み案

## 推奨案：再挑戦チケット

ケースC（非テイカー初投稿無料、テイカー初投稿・更新は難易度P、総還元`S+C`、改案順位配分）を基礎に、下位・低残高プレイヤーへポイントではなく用途限定の「再挑戦チケット」を発行する。

### 発行条件

場札回収時に、プレイヤー`u`が次をすべて満たす場合、チケットを1枚発行する。

- 投稿参加者数`N >= 3`
- 最終順位`r_u > ceil(N/2)`。すなわち下位`floor(N/2)`人相当
- 回収・通常還元を反映した後の所持ポイント`P_u <= 5`
- 未使用チケットを持っていない
- 前回のチケット発行から120分以上経過している

標準競技順位の同率順位が境界をまたぐ場合は、その順位グループ全員を同じ扱いにする。境界順位の全員を対象にすると発行人数が半数を超える場合があるため、実装前に「全員対象」か「全員対象外」を固定する。公平性を優先するなら全員対象を推奨する。

### 効果

- 他プレイヤーがテイクした場札へ無料の初投稿を行った後、その同じ場札で行う最初の有料更新1回を無料にする
- 難易度1〜5の費用を全額免除し、0Pでも利用できる
- テイカー初投稿、ドロー、返却、任意延長には使用できない
- チケット利用分は実支払いポイント`C`へ加えない。従って総還元`S+C`も増やさない
- 発行から6時間または大会終了時の早い方で失効する
- 保有上限は1枚。譲渡・換金・複数枚利用は不可

これはポイントを直接発行せず、1回の更新費だけを免除する。定期給付を待たず、次に見つけた場札で2回目の挑戦まで進める。難易度5でも2.5時間待つ必要がなく、用途が更新に限定されるため、ドロー貯蓄や巨大スタック形成へ転用されない。

### 悪用抑制

- 意図的に下位を取ると、その場札のランクPとホルダー機会を失う
- チケットは1枚しか保持できず、120分の再発行間隔と6時間の期限がある
- 更新は自己ベストを実際に更新したときだけ成立し、失敗試行では消費しない
- 自分がテイクした場札では使えないため、秘密練習済みカードへの自己補助にならない
- 通常Pとして残らず、大会終了時残高を膨らませない

## なぜ定期給付だけでは不足し得るか

30分ごとに1Pなら、0Pから難易度5の投稿費5Pまで最大2.5時間を要する。場札の初期期限は難易度1・2で60分、難易度5でも120分なので、給付だけでは参加したい場札の期限へ間に合わない。問題は大会全体のP不足より、必要な瞬間に用途へ使える流動性がないことにある。

一方、無条件に給付量を増やすと、使わず貯める参加者、上位者、終盤に使い切れない参加者にも同額を発行する。再挑戦チケットは、直前の敗戦、低残高、次の更新という3点へ対象を限定できる。

## 補助案：活動連動1P

再挑戦チケットだけではドロー・テイク数が回復しない場合に限り、次を追加比較する。

- 有効な初投稿を完了した時点で`所持P + 手札枚数 <= 2`なら1P付与
- 1人につき120分に1回まで
- 場札1枚につき1回、削除・再投稿で再発行しない
- 大会終了1時間前以降は発行しない

こちらはドローへ使えるため再テイクを助けるが、無料初投稿を給付目的で巡回する誘因がある。先にチケット単独を試し、下位層の更新は増えるがドロー・テイクが戻らない場合だけ追加する。

## 推奨しない案

- 最下位へ無条件で通常Pを配る：意図的最下位、複数アカウント、P貯蓄の誘因を作る
- ランクP順位に応じて定期給付する：大会序盤の順位変動が大きく、低順位維持を戦略化しやすい
- 全員の給付を一律増額する：流動性問題のある本人以外にも供給し、終了時残高だけを増やしやすい
- 借入・マイナス残高：返済不能、終盤の踏み倒し、UI説明が複雑になる

## シミュレーション採用基準

ケースCを対照に、チケット単独、活動連動1P単独、両方の4条件を同一seedで比較する。下位コホートはケースCで最終ランクP下位4人に固定する。

主判定は次のとおり。

- 下位層の活動中0P以下率と2P未満率が相対20%以上低下
- 下位層の初投稿後更新数が10%以上増加
- 下位層のドロー・テイク数が悪化しない
- 大会全体の終了残高がケースC比15%以上増えない
- 意図的下位を模したプレイヤーのチケット取得数が通常下位層の2倍を超えない
- 無投稿回収、場札数、回収数、ランクP総量がケースC比10%以上悪化しない

チケット単独で基準を満たすなら、活動連動1Pは追加しない。制度を一つに保ち、通常ポイント供給を増やさずに再参加だけを支援できるためである。
