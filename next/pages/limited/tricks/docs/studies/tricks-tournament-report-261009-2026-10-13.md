### ランク帯と分母

### 費目の定義

| 分類 | 集計方法・注意点 |
|---|---|
| 還元 | collect.contextのdistribution＋taker_remainder。還元台帳と照合し、片方だけを加算する。端数還元8Pを含む |
| 即時支給 | instant_subsidy_paidをreason=take/free_postへ分離。行動直前DP＋手札<5で支給された実額 |
| 定期支給 | subsidy_paidの実支給額。DP＋手札<3。定期スロットの理論最大支給額ではない |
| その他収入 | 参加時5P、後発参加時の既存者1P。後発ボーナスはjoinの既存参加者集合へ適用し、新参加者本人には付けない |
| テイカー自身の投稿 | payment_type=initial_postかつ有料の初投稿だけ。今回90回163Pで、支払い者がテイカーであることを確認 |
| 記録更新投稿 | payment_type=score_updateの全費用。テイカー自身の更新もこちらへ分類し二重計上しない |
| ドロー／返却 | 成功したdraw／return_to_deckの実費。返却後のドローは別のドロー費 |
| 延長 | player_extensionの実費。初投稿の自動延長は0Pなので含めない |
| その他支出 | balance_tax_collectedの実徴収額。投稿費・延長費・返却費が後で還元されても支出を相殺しない |

## 6. 資金循環・不足・終盤偏重

### 還元の原資

143回収すべてで、投稿者がいれば **Q=S+B+C+ポット**、0人ならQ=0が成立した。

| 原資 | 実際の還元へ入ったP |
|---|---:|
| 投稿者あり札の物理トリックS | 756 |
| 同レア度ボーナスB | 239 |
| 同投稿費・任意延長費C | 556 |
| 回収へ移されたポット | 145 |
| 合計 | 1,696 |

全投稿・延長費は561Pだが、無投稿札に使われた延長5Pは還元されない。税132P＋返却13P＝ポット145Pはすべて再配分され、終了ポットは0P。税は大会全体での通貨消滅ではなく、プレイヤー間の再配分である。

無投稿17札ではS=99P相当・B=10P相当の**予定原資が未発行**となる。これと支払い済み延長5Pの**消滅**は区別する。大会全体の通貨保存式は次のとおり。

```text
初期・後発180 + 即時・定期141 + 回収S/Bの新規発行995
− ドロー963 − 無投稿札に支払った費用5 = 終了残高348P
```

### 資金不足の実測

- 投稿費によるDP負数は**8人**に発生。最低残高は−5P。現行シミュレーターはallow_post_debt=Trueであり、負債の許可自体は実装済み。頻度と回復速度を校正する必要がある。
- DP負数の合計は8.83人時間。参加登録後時間で加重した負数時間率は上位1.08%、中位2.20%、下位0.75%。
- DP＋手札<3の時間率は同じ分母で上位6.75%、中位5.36%、下位3.86%。帯別に不足条件滞在時間と実際の給付を比較する。
- 時間積分した全参加者のDP平均は**11.10P/人**に対し、終了平均は23.20P/人。終了残高だけでは開催中の流動性を説明できない。
- 閉幕時強制回収6札の還元は143Pで、総還元の8.4%。P11はこの境界で55Pを受けた。閉幕還元は終了後に再消費できないため、開催中に使えた資金と分ける。

時間率はログ適用直後から次ログまでを積分した値。即時給付と本体操作が別ログのため、同一操作内部の短い状態を含む可能性がある。ログはログイン・離席・練習を記録しないため、上記を「活動中の不足率」や実労働時間とは呼ばない。

### 終盤のドロー

テイク締切の10/11 18:59:00以降も**44回のドロー**がある。終了時手札は95枚。ドローは通貨の支出ではあるが、全てが有効なテイクへ転換されたわけではない。現行モデルは締切後ドローの効用を0とみなし候補から除外しており、実行動との差がある。理由が収集・カード確認・締切誤認等のどれかは生ログから確定できない。

## 8. シミュレーター改善の優先項目

## 9. ルール調整を試すなら

現時点では正式ルールを変更せず、次の比較条件を準備するのが妥当。

1. **延長回数／延長上限の比較**：無制限、1人×1札の回数制限、札全体の期限上限を比較する。長寿命・参加者数・他者の機会・総還元・P循環・場占有を評価する。現行の他者札延長の便益もあるため、一律削減が改善になるとは限らない。
2. **高レア度・単独投稿還元の比較**：現行、単独投稿だけのボーナス調整、ボーナス上限等を別々に比較する。遅参者の復帰機会、還元集中、無投稿率、ドロー意欲への影響を測る。レア度5は2札しかなく、今回だけでは調整幅を決めない。
3. **給付の比較**：現行の5/3閾値を対照に、閾値・額・頻度の候補を分離して比較する。RP下位だから一律増額するのでなく、活動中の低資源・負債・投稿不能・テイク機会を指標にする。今回は失敗行動を記録していないので、投稿不能の実測はできない。
4. **終盤資源の比較**：閉幕時にしか使えない還元と、締切後の不要／別目的ドローを区別する。終了前の回収・告知・ドロー方針の候補を検証し、最終残高の多さだけをインフレ判定に使わない。

税や延長費を変えると次の札の還元や活動まで変わる。この大会の既存行動を固定して費用だけ差し替えた計算は、機械的な収支感度に限定し、改定後の行動や成績の予測とは扱わない。
