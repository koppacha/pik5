# 投稿費・還元4ケース比較

## 結論

下位プレイヤーの大会中の資金繰りは、ケースBで明確に悪化、ケースCは現行とほぼ同等、ケースDは平均残高がやや悪化した。比較した中ではケースCが最も良いが、「現行より資金繰りが改善した」とまでは確認できない。

ケースCは現行に対し、終了残高+1.58P、初投稿+0.30回となった一方、活動中平均残高は-0.04P、0P以下率は+0.39ポイント、2P未満率は+0.09ポイント。後3指標の参考95%区間はいずれも0を含み、実質的に現行並みだった。

## ケース

- A：現行。非テイカー初投稿無料、テイカー初投稿と全更新は難易度P。現行の控除、難易度ボーナス、順位配分
- B：非テイカー初投稿1P、テイカー初投稿と全更新は難易度P。総還元`S+C`と改案配分
- C：非テイカー初投稿無料、テイカー初投稿と全更新は難易度P。総還元`S+C`と改案配分
- D：場札の最初の投稿者はテイカーを含め無料。以後の初投稿・更新は、投稿後の順位`r <= floor(N/2)`なら難易度P、下位半分なら無料。総還元`S+C`と改案配分

Dはユーザー例を優先した解釈である。原文の「少ないなら」と4人時の「1〜2位なら有料」には境界差があるため、4人時2位を含む`<=`とした。また「それ以外は難易度分」は例と矛盾するため「それ以外は無料」と解釈した。更新も投稿後順位で同じ判定を行う。上位スコアを出しても難易度Pを所持しない場合は投稿できない。

## 比較条件

- 48時間、16人、山札200枚、同一seed 281000〜281099の100大会×4ケース
- 現行の参加時刻、活動時間、スキル、給付、返却、任意延長、平方根レベル式、クールダウンを維持
- 下位層は各seedのAで最終ランクP下位4人を選び、その同じプレイヤーをB〜Dでも追跡
- 活動中指標は30分スナップショットのうち本人の活動時間内だけを集計
- スコアは連続値で、実験中は端数配分を必要とする同点を前提にしていない。異なる順位の同額配分は改案基底どおり許可

## 判定

- B：不合格。初投稿1Pの先払いにより、下位層の活動中残高、0P率、2P未満率、ドロー、テイクが明確に悪化した
- C：4案中の第一候補。活動中の資金繰りはAと統計上区別できず、終了残高・初投稿・下位層ランクPは増えた。ただしテイクは平均0.083回減り、積極的な改善とまではいえない
- D：Bより良いがCより劣る。0P率・2P未満率はAとの差が不明確だが、活動中平均残高は0.32P低下した。順位が上がった瞬間だけ課金されるため、競技上の成功へ追加コストを課す複雑さもある

採用候補はC。次に、Cのテイク減少が新配分によるものか、総還元増加による終盤の行動選択変化かを確認する。資金繰りを明確に改善したいなら、Cへさらに給付を足す前に、回収までの待ち時間と下位配分を調整する方が原因に直接対応する。
