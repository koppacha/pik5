# next/lib

このディレクトリには、フロントエンド全体で共有されるユーティリティ、データアクセス、認証補助、SEO 補助が置かれています。以下が特に重要です。

## 重要ファイル

### `pik5.js`
- もっとも広く使われている共通ユーティリティ集です。
- 翻訳切替 `useLocale`、日付整形、秒数変換、ランク色、シリーズ判定など、画面表示の基礎関数が集約されています。
- 画面上の表示仕様が複数ページで同時に崩れた場合はまずここを疑います。

### `prisma.js`
- Next.js 側で使う Prisma クライアントのシングルトン定義です。
- 開発時の接続使い過ぎを避けるため `global` に保持しています。
- `pages/api` やキャッシュ処理から DB を触る入口です。

### `usersCache.js`
- ユーザー一覧をメモリキャッシュする層です。
- `getCachedUsers()` と `getCachedUsersWithRole()` を通じて、SSR 時のユーザー名解決や権限付き一覧取得を軽量化しています。
- トップページ、記録詳細、検索候補などの土台になっています。

### `serverApiAccess.js`
- `/api/server/*` 系 API のアクセス制御を担います。
- same-origin 判定、短命アクセストークン発行、Cookie 検証を実装しており、Laravel へのプロキシ入口を保護しています。
- API セキュリティや 403 調査時の最優先確認箇所です。

### `seo.js`
- URL 正規化、多言語 URL 生成、絶対 URL 化を担当します。
- `SeoHead.js` から利用され、canonical や alternate の整合性を支えています。

### `axios.js`
- Laravel 直通の Axios クライアント定義です。
- 現在は `fetch` 利用が多いものの、旧実装や一部処理の参照元として残っているため、API ベース URL の確認に役立ちます。

### `logger.js`
- Next.js 側のロギング基盤です。
- 認証や API エラーのトレースで参照されます。
- 本番障害の調査時に関係しやすいファイルです。

### `emailCrypto.js`
- メールアドレスの暗号化・復号に関わる処理です。
- NextAuth のセッション生成時にも使われており、認証情報の扱いに影響します。

### `recordNotification.js`
- 記録通知まわりのデータ整形や通知発火補助を担います。
- 通知 UI 側の `components/notifications/*` とあわせて確認してください。
