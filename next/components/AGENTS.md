# next/components

このディレクトリでは、ページをまたいで再利用される UI コンポーネントを管理しています。以下は開発時に特に重要なファイルです。

## 重要ファイル

### `Layout.js`
- 全ページ共通のレイアウトです。
- `HeaderMenu`、`Footer`、`MobileFooter` をまとめて描画し、`pages/_app.js` から全ページに適用されます。
- 共通 UI を差し替える場合の起点です。

### `SeoHead.js`
- 各ページの `<head>` を組み立てる共通コンポーネントです。
- canonical、`hreflang`、OGP、Twitter Card、JSON-LD をここで設定します。
- SEO や多言語対応に関わる修正はまずここを確認してください。

### `menu/HeaderMenu.js`
- PC 向けヘッダーメニュー本体です。
- シリーズ別メニュー、検索モーダル起動、テーマ切替、言語切替、ランダムステージ遷移を担当します。
- ヘッダー導線やグローバルナビの変更点はここに集まりやすいです。

### `menu/MobileFooter.js`
- モバイル向けの固定フッターナビです。
- スマホ表示時の主要導線を担うため、ヘッダー修正時はあわせて確認が必要です。

### `record/Record.js`
- 記録カードの表示ロジックをまとめた中核コンポーネントです。
- 順位、比較値、日時、証拠画像、動画リンク、比較導線などを描画します。
- `/stage/*`、`/record/*`、ランキング系ページに広く使われるため、影響範囲が大きいファイルです。

### `modal/RecordForm.js`
- 記録投稿・再編集フォームです。
- バリデーション、画像圧縮、`/api/server/post` への送信、投稿後の再検証トリガーまで担います。
- 投稿仕様の変更時はフロント側の主な修正箇所になります。

### `top/DashBoard.js`
- ログインユーザー向けダッシュボードです。
- `/api/server/user/total/*` や総合順位データを読み、進捗や近傍順位を可視化します。
- トップページのログイン後 UI や個人進捗ロジックを追うときの起点です。

### `notifications/RecordNotificationCenter.js`
- 投稿更新通知の受信と表示の中心です。
- リアルタイム通知やトースト表示の入口として機能します。
- 通知仕様を触る場合は `notifications/` 配下をここから追うと把握しやすいです。
